## Notes (saved from user message)

Finding raw sample sonar files often requires looking through specialized repositories or manufacturer-specific SDKs, as most public data is provided in processed formats like GeoTIFF.

1. Repositories for Raw Data Files
These repositories host raw binary files from specific manufacturers:
- EdgeTech (*.JSF): You can find raw EdgeTech sidescan files (JSF format) in the NBP0505 dataset on Marine Geoscience.
- Kongsberg/Simrad (*.ALL, .KMALL, .RAW): The NOAA NCEI Multibeam Bathymetry Database contains millions of miles of ship trackline data from makers like Kongsberg and Reson.
- Generic/Multiple Makers (*.XTF): The USGS Science Data Catalog provides eXtended Triton Format (XTF) files, which is a common exchange format for sidescan and multibeam from various manufacturers.
- Community Curated: The OpenSonarDatasets GitHub repository acts as a directory for open-source sonar data, including deep-sea and shipwreck datasets.

2. Common Manufacturer File Formats
| Manufacturer | Common File Formats | Details |
| :--- | :--- | :--- |
| Kongsberg | .ALL, .KMALL, .RAW | Standard for EM series multibeam systems. |
| EdgeTech | .JSF | Used for both sidescan and sub-bottom profilers. |
| Teledyne Reson| .S7K, .PDS | Standard for SeaBat multibeam systems. |
| Klein | .SDF | Specific to Klein sidescan sonar systems. |
| Lowrance/Simrad| .SL2, .SL3 | Common in consumer and light-professional systems. |
| Humminbird | .DAT | Found in recreational side-imaging units. |

3. Developer & SDK Samples
Manufacturers sometimes include sample files within their software development kits (SDKs) to help developers test integration:
- Teledyne BlueView: Offers an SDK that includes example files to demonstrate raw data collection and processing.
- MB-System: This open-source software project maintains documentation and format specifications for dozens of legacy and current sonar formats.
