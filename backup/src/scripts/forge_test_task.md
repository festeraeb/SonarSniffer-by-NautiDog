- [ ] Implement warp-grid/src/scheduler.rs — a GridScheduler that analyzes ComputeTask cost and selects the optimal device. Select device based on available VRAM, current utilization (Arc<AtomicU64>), and NUMA locality (prefer device on same socket as calling thread). Support multi-device sharding if task VRAM exceeds single device. Use enum dispatch with Hardware variants (Pascal/Turing/Volta/Xeon/TPU/RemoteNode/WebGpu). Include a DispatchTier selection: known hardware gets Specialist path, unknown gets Adaptive. Pattern: extend the route_task! macro from cesarops-hybrid-engine/src/scheduler.rs. Dependencies: use types from warp-grid/src/types.rs (ComputeTask, DeviceProfile, Hardware, DispatchTier, Precision, Error). Must compile standalone with cargo check.
